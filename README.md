# Café Cantinho

Jogo isométrico 3D de cafeteria para navegador. Código em `js/`, build num HTML único.

```bash
npm install
python3 build.py     # → dist/index.html
npm run serve        # http://localhost:8766
```

Contexto do projeto, arquitetura e armadilhas conhecidas: veja `CLAUDE.md`.
Publicação gratuita (GitHub Pages + Firebase): veja `DEPLOY.md`.

Modelos 3D: KayKit (Kay Lousberg) e Mini Characters (Kenney); sons: Impact Sounds (Kenney). Todos CC0 — licenças em `assets/licenses/`.
